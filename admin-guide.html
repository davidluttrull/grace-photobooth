Harvest Family Night Photo Booth

Admin Guide

How it fits together

Families sign in on an iPad instead of the paper sheet. A volunteer adds the camera’s photo number to each sign-in. After the event, the Google Sheet emails every family their photo.

The pagedavidluttrull.github.io/grace-photobooth. What the iPads open. It has two modes, Sign-In and Photo Numbers.
The Sheet2027 HFN Photo Booth Sign-Ins, the copy in the church Google account. Each sign-in is one row on the Sign-Ins tab.
The scriptInside the Sheet (Extensions → Apps Script). Code.gs saves sign-ins and photo numbers. Sender.gs adds the Photo Booth menu that emails the photos.
The codegithub.com/davidluttrull/grace-photobooth, with a copy in the Project Files folder next to this guide.

The iPads don’t sign in to Google. Each one needs the staff code once, and the page only works with it.

The staff code

To see or change it: open the Sheet, then Extensions → Apps Script → Project Settings (the gear) → Script Properties → STAFF_CODE.

  • A new code works right away; nothing needs redeploying. Each iPad asks for the new one the next time it talks to the Sheet.
  • After 20 wrong codes in 10 minutes, from any device, the Sheet refuses everything for 10 minutes. That stops anyone guessing the code.
  • Give the code to the volunteers at the booth, not in a public post. Anyone with the code can see the names of the families who signed in.

Before the event

  • Charge the iPads, and check they connect to the building’s Wi-Fi where the booth will be.
  • On each iPad, open the page in Safari, enter the staff code, then Share → Add to Home Screen. It shows up as Photo Booth.
  • Set each iPad to its job with the buttons at the top right: Sign-In or Photo Numbers. It stays on that one.
  • On the sign-in iPad, turn on Guided Access (Settings → Accessibility → Guided Access) so families stay in the page. Triple-click the side button to start and end it.
  • Do a test run: sign in a pretend family, add a photo number on the other screen, and check the row appears in the Sheet with Ready to Send checked. Then delete the test row.
  • Set the camera’s file numbering to continue (not reset) so numbers don’t repeat during the night.
  • Print the Volunteer Guide for the booth.

During the event

You can watch the Sign-Ins tab fill in from any computer or phone. Each row has the sign-in number, the time, the family’s name, email and phone, and the photo number once a volunteer adds it.

  • Saving a photo number checks Ready to Send, unless the family left no email.
  • You can fix a typo in a name or email, or delete a test row, right in the Sheet. The iPads pick up the change within a few seconds.
  • Leave the header names in row 1 as they are. The script finds its columns by those names. Adding your own columns to the right is fine.

After the event: sending the photos

  1. Upload the edited photos folder to the church account’s Google Drive. The files should keep the camera’s names (DSC00527.jpg; an edited DSC00527-2.jpg is fine too).
  2. On the Email Settings tab, type the folder’s exact name. Check the subject, message and sender name. {name} in the message becomes the family’s name.
  3. Look over the Sign-Ins tab. Uncheck Ready to Send on any row you want to hold back.
  4. Photo Booth → Match photos from Drive links each row to its file. MISSING means a photo number with no file in the folder: ask the photographer for it, or fix the number.
  5. Photo Booth → Send a test email to me. Check the From line, the message and the attachment.
  6. Photo Booth → Send photos to checked rows. It asks before sending, then puts the time in Sent as each email goes out.

No double sends. Sending again skips every row with a time in Sent. If it stops partway (Google allows about 6 minutes per run), run it again to finish.

To resend to one family, clear their Sent cell and run it again.

Bounces come to the church inbox. Fix the email in the Sheet, clear Sent, and resend. Families with no email have a phone number for a text instead.

Which account sends the email

The emails come from whichever Google account runs the Photo Booth menu. The Sheet is in the church account, so they come from david.luttrull@gracetoanderson.com as Grace Baptist Church.

The ICA account can’t send as the church address: ICA’s Workspace blocks sending through another domain’s mail server. Always run the menu from the church account.

Changing the page or the script

The page

Edit index.html in the GitHub repo and commit. GitHub Pages updates in a minute or two. The iPads get the new version the next time the page loads.

The script

  1. Paste the new Code.gs or Sender.gs into Apps Script and save.
  2. With Code.gs open, run setup once. That’s where Google asks for any new permission.
  3. Deploy → Manage deployments → pencil → Version: New version → Deploy.

Never use New deployment for an update. It makes a new web address, and the page would stop reaching the Sheet.

Next year

  1. In the church account, make a copy of this year’s Sheet, rename it for the new year, and delete the rows below the headers on Sign-Ins.
  2. In the copy, open Apps Script and run setup. Note the new staff code from the Execution log.
  3. Deploy → New deployment → Web app, with Execute as Me and access Anyone. Copy the /exec URL.
  4. In index.html, replace the URL on the const API_URL = line and commit it.
  5. Each iPad asks for the new staff code the first time it’s used.

Troubleshooting

The iPads say “Couldn’t reach the sign-in sheet”
Check the Wi-Fi first. Then open the /exec web app URL in a browser: it should show {"status":"ok"}. If it shows a Google error page, wait a minute and try again. A brand-new deployment can take a moment to start answering.
“Too many wrong codes. Wait 10 minutes and try again.”
Someone entered the wrong staff code 20 times. It clears itself after 10 minutes.
“The staff code hasn’t been set up yet”
Run setup in Apps Script.
“No Drive folder named …” when sending
The folder name on Email Settings doesn’t exactly match the folder in Drive, or the folder is in a different account.
“Gmail will not send as …”
The Send from address on Email Settings isn’t the account running the menu. Run it from the church account, or clear that cell to send from whoever is signed in.
Two families have the same photo number
Look at the photo to see which family it is, then fix the other row’s number in the Sheet.
